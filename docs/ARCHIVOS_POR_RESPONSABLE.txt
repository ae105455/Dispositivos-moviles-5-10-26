PARA QUE LOS DATOS SE GUARDEN EN XAMPP
--------------------------------------
1. En XAMPP inicia Apache y MySQL.
2. Si aun no existe pulso_dance, importa docs/xampp_pulso_dance.sql en
   http://localhost/phpmyadmin.
3. Abre http://localhost/pulso_api/catalogs.php y confirma que responde
   success:true.
4. Ejecuta flutter run -d chrome. En Chrome, la app usa esa API por defecto.
5. Pulsa Guardar evaluacion. El formulario solo muestra exito cuando PHP
   confirma que MySQL guardo la evaluacion.

Para Android Emulator, la app elige automaticamente 10.0.2.2. En un telefono
fisico hay que reemplazar localhost por la IP local de la PC:
flutter run -d android --dart-define=PULSO_API_URL=http://192.168.1.20/pulso_api

La carpeta xampp/htdocs/pulso_api de esta computadora esta enlazada al directorio
xampp/pulso_api del proyecto. En otra computadora hay que copiar ese directorio
a C:\xampp\htdocs\pulso_api.
